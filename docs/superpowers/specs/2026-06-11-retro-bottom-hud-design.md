# Retro Bottom HUD Design

## Goal

Move the current Read the Room feedback out of the chat rail and into a full-width bottom game HUD, add a level-specific velvet-rope status bar between that feedback and the send controls, and make the non-generated UI components feel more like a polished retro pixel-art game interface.

## Approved Direction

The approved layout is Option C from the visual companion: the stage and conversation stay in a two-column desktop layout, while the bottom control console spans both columns.

Desktop order:

1. Stage scene on the left.
2. Conversation log on the right.
3. Full-width HUD below both columns.
4. HUD content arranged as Read the Room, status bar, text input, Send, Reset.

Mobile order:

1. Stage scene.
2. Conversation log.
3. Read the Room.
4. Status bar.
5. Input and buttons.

## Components

### Read the Room

Read the Room remains a qualitative hint panel. It should sit in the bottom HUD instead of inside the chat panel. It keeps the current mood label, mood dot, and hint text, but its styling should become more compact and pixel-framed.

### Velvet Status Bar

The status bar is a new HTML component rendered from the current game state. It should display the existing status-line copy and include a per-character class so each level can have its own visual treatment.

The app should support future image assets for the status bar without requiring them to exist immediately. The intended future manifest keys are:

- `marlowe`: `assets/status_marlowe_rope.png`
- `vivienne`: `assets/status_vivienne_rope.png`
- `crispin`: `assets/status_crispin_rope.png`
- `lenore`: `assets/status_lenore_rope.png`
- `aurelia`: `assets/status_aurelia_rope.png`

Until those images are available, CSS should provide a pixel-art fallback with level-specific colors and motifs. No generated images are part of this change.

### Input Controls

The player textbox, Send button, and Reset button move into the bottom HUD. Send should remain the primary action. Reset should remain visible but quieter.

### Retro UI Polish

The interface should move away from glossy nightclub panels and toward a Stardew-like pixel UI language:

- Chunky double borders.
- Flat dark panels with gold and rope-red accents.
- Crisp edges and nearest-neighbor rendering for images.
- Compact HUD typography.
- Stable heights for stage, chat, HUD, buttons, and input.
- No new raster images generated by Codex.

## Asset Generation Prompt

Use this prompt with the user's asset image generation AI after the code adds the hooks:

```text
Create five separate transparent PNG pixel-art horizontal HUD status bars for a retro dialogue game called Velvet Rope. Each image should be 960x96 px, 2D pixel art, crisp edges, no blur, no antialiasing, no text, no characters, no background outside the bar, transparent background, high quality game UI asset, cozy polished retro RPG interface style inspired by Stardew Valley UI quality but original.

All five bars must share the same layout and silhouette so they can occupy the same HUD slot: left and right end caps, a central readable area for overlaid text, decorative rope or gate detail along the bottom edge, and enough dark interior contrast for pale gold text placed on top.

Make one PNG for each level:
1. marlowe: classic nightclub velvet rope, brass posts, deep burgundy cord, warm worn gold trim, subtle pavement/nightclub door details.
2. vivienne: cosmic bureaucracy dream gate, burgundy rope blended with glowing filing-tab shapes, tiny stars, ledger corners, cool violet-blue shadows with gold trim.
3. crispin: hollow tree cookie factory gate, braided red rope with cookie conveyor hints, carved wood end caps, warm bakery golds, small cookie rivets.
4. lenore: haunted theater stage door rope, burgundy curtain cord, brass theater hardware, small marquee bulb accents, aged black-red stage paint.
5. aurelia: grand threshold hospitality rope, elegant ceremonial cord, polished threshold arches, invitation motifs, refined gold and emerald accents.

Output each as a separate file named:
status_marlowe_rope.png
status_vivienne_rope.png
status_crispin_rope.png
status_lenore_rope.png
status_aurelia_rope.png
```

## Testing

Add tests that confirm:

- The Gradio layout has a full-width bottom HUD separate from the chat panel.
- Read the Room still renders current mood and hint text.
- The new status bar renders status copy, character classes, and accessible text.
- CSS includes the retro HUD classes and responsive stacking.
- The future asset filenames are documented in code or CSS without requiring missing files.

## Out Of Scope

- Generating or committing new image assets.
- Changing persuasion logic, model backends, validation thresholds, or character writing.
- Redesigning the generated pixel sprites or scene backgrounds.
